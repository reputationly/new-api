Compliance checklist (apply silently before answering; these restate the rules above):
1. Coverage first. Part 1 is a complete inventory of the source-derived content that appears in the target, not only the edited element. Define the overall scene/background/canvas of each base picture as a Subject, define the edited element(s), and define every clearly readable text element (signs, labels, titles, slogans, captions, UI strings, menu items, prices, chart titles, axis ticks, legend entries, data values, table headers and cells, handwriting) as a Subject or as part of a text-block Subject, transcribing every line verbatim inside single quotes in its original language and script. Unchanged elements are still defined and then marked fully preserved. Never write that readable text is unreadable or omit a readable line because it is unchanged.
2. Every definition sentence names its source with an explicit '<Picture N>' and follows the pattern '... in <Picture N> is <Subject N>.' (or '... are <Subject N>.'). Number Subjects 1, 2, 3, ... in order of first definition.
3. Do not define a Subject for something that is removed or wholly replaced; mention it once in the target overview with its <Picture N> and describe the filled-in result in Part 3. Every defined Subject must end up fully preserved, partially preserved, transferred, or weakly referenced.
4. Part 2 starts with exactly one sentence beginning 'The target image'. Then one separate sentence per Subject, in Subject order: '<Subject N> is fully preserved.' exactly, with nothing appended, or '<Subject N> is partially preserved; <retained categories> remain, while <changed categories> change.', or an explicit transfer / weak-reference clause.
5. Part 3 describes only changed or new content, richly and concretely, and gives the complete final wording of every changed or new text in single quotes.
6. All prose is English. Non-English characters may appear only inside single-quoted literals. Never use double quotation marks for literals. Grids are described as 'R rows and C columns'.
7. target_aspect_ratio: an explicit user selection wins; otherwise an explicit ratio/orientation in the instruction; otherwise copy the main edited picture's supplied aspect_ratio exactly, even when it is not a common ratio.
8. Relationship accuracy. 'Fully preserved' means nothing about the Subject changes: if its position, size, scale, orientation, crop/framing, carrier, form, or state changes in the target, it is partially preserved. An element taken from one picture and placed, worn, printed, or moved into the target is never fully preserved. If the target aspect ratio or framing differs from the base picture, the base scene Subject is partially preserved.
9. Replacement. An element that is replaced or removed gets no Subject and is never called preserved; mention it once in the overview with its <Picture N>. When the replacement comes from another picture, define that donor as a Subject with its own <Picture N> and keep its identity traits (expression, markings, colors, accessories) unless the instruction changes them.
10. Text fidelity. Every clearly readable text must be transcribed verbatim, character by character, exactly as in Part 1 rules; never skip readable text. Only for text that is genuinely too small, blurred, or hidden to read, say it is illegible; never guess, complete, or invent characters, words, or brand names you cannot actually read.
11. Scope. Apply the instruction exactly to the elements it names, in the positions it names (for example, switching one toggle does not restyle the whole interface; swapping two named cells moves only those two). Choose one concrete arrangement for the changed content; never offer alternatives with 'or'.
