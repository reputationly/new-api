时段建好之后，怎么给模型配价格（4 步）

关键：「模型定价」页只放常规目录价（基准）；「分时价」面板里，每个时段给这个模型写一份该时段的绝对价。高峰通常就等于常规价，空闲是它的一半。
1在左下角把模型加进来时段区已经建好「高峰时段 / 空闲时段」，这一步是把模型和时段接上
已配置的模型（0）
搜索模型▾
deepseek-v4-1-flash
常规目录价（模型定价页）　输入 ¥2.0000　输出 ¥8.0000　缓存命中 ¥0.0400
高峰时段工作日 09:00-12:00、工作日 14:00-18:00
输入2.0000×1.000
输出8.0000×1.000
缓存命中0.0400×1.000
点「+ 添加模型」后，会自动带上第一个时段（高峰）+ 预填常规价，右侧立刻出现这张卡片——所以高峰这一档通常什么都不用改。
2用卡片区底部的「添加时段」下拉，把空闲时段挂上
已配置的模型（1）
deepseek-v4-1-flash1 个时段
高峰时段工作日 09:00-12:00、工作日 14:00-18:00
输入2.0000
输出8.0000
缓存命中0.0400
添加时段▾ ← 下拉里选「空闲时段」，卡片就出来了
下拉里只会出现还没给这个模型配过的时段，所以不会重复。
3在「空闲时段」卡片里，把三个数改成官方闲时价
已配置的模型（1）
deepseek-v4-1-flash2 个时段
空闲时段其余时间（除「高峰时段」以外）
输入1.0000×0.500
输出4.0000×0.500
缓存命中0.0200×0.500
三个框都要填：输入 1、输出 4、缓存命中 0.02。留空表示"这个分量不随时段变"——只填输入的话，闲时会出现"输入降一半、缓存没降"的怪价。
4点右上角「保存分时价」，两档价格就位
已配置的模型（1）
deepseek-v4-1-flash2 个时段
高峰时段工作日 09:00-12:00、14:00-18:00
输入2.0000×1.000
输出8.0000×1.000
缓存命中0.0400×1.000
空闲时段其余时间（除「高峰时段」以外）
输入1.0000×0.500
输出4.0000×0.500
缓存命中0.0200×0.500
客户实付（5 折）：高峰 1 / 4 / 0.02，空闲 0.5 / 2 / 0.01。广场与详情页显示的就是这个数。
