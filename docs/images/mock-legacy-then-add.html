「之前已经配过」再添加时会发生什么

前提：这个模型在旧面板时期已经配了 3 条规则（夜间 / 午休 / 周末，都是单段）。下面三种情形按顺序看。
1升级后第一次打开：老配置照样在，照样生效（不会丢）

缓存命中0.0200×0.500
另外两条（午休 / 周末）同样显示，结构不变 → 可以继续用，也可以就地改
2再建「其余时间」并挂到这个模型 —— 能加进列表，但保存会被拒绝

← 与午休/周末重叠
保存失败：group * time rule "m": window "rest" is the complement (rest-of-time) and covers "noon"; remove the other windows or narrow the complement
原因不是"不能加"，而是< b>这两套时段描述的是同一段时间：旧的三段已经覆盖了全天，再加一个"其余时间"必然重叠，同一分钟会有两个价。
3正确做法：把旧的三个时段换成一个「其余时间」，只保留要区分的那一档
