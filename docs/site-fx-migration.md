# 全站汇率统一：上线与回滚

- 唯一实时人民币／美元换算参数是模型定价页的 `ModelSourceRate`。CFETS 中间价只供参考。旧 `USDExchangeRate`、`QuotaPerUnit` 不再加载或接受写入；旧版客户端的状态字段分别从 `ModelSourceRate`、`ModelSourceRate × QuotaPerYuan` 派生。
- 首次启动在 `options` 的 `_internal.site_fx_legacy` 备份已存在的 `USDExchangeRate`、`QuotaPerUnit` 和 `Price` 原值；重复启动不会覆盖备份。旧行保留，迁移不重算任何余额、订单、流水或日志。此操作不是旧版配额缩放迁移，不要为这次升级运行后者。
- 上线前核对有效汇率和收款口径。本次核对值为 `ModelSourceRate=6.8`、`USDExchangeRate=Price=7.3`、`QuotaPerUnit=7300000000`，因此支付宝、微信直付散充面值及套餐售价、对公实际到账金额均按固定每元 `1000000000` quota 入账，¥100 对应 `100000000000` quota。直付散充的实际扣款、折扣和分组倍率保持原规则；不应拿折后实付额代替到账面值。配置不满足原先 1:1 的站点需先评估差异再上线。
- 上线窗口暂停建单，核查 `top_ups` 无待支付、`bank_transfer_orders` 无待审核后再切换。已存储到账 quota 的直付存量订单继续按原 quota 完成；未使用的 Stripe／易支付／Waffo 外币订单不要跨切换或汇率调整未结，否则尚未完成的外币金额会按入账时汇率换算。Creem 已存额度不变。
- USD 视图把人民币金额除以汇率，CNY 视图不换汇。消费日志用记录的实际汇率，未记录的历史美元口径按 7.3 兼容并标记估算；不会重结算旧账。报价表达式及相关上游美元成本折算使用请求快照。
- 回滚前同样暂停建单并清理未结订单；备份当前数据库以供核对，回到上一个程序版本。确认旧键原值仍在；如已删除或改动，按内部备份逐项恢复旧键，未存在的键继续保持缺省，不要回灌整个数据库。仅当需要撤销本次另行修改的商业售价时恢复 `Price`。重启各节点后核对渠道和管理员审计，不能重发已完成订单。
